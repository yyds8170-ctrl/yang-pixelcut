# 洋洋 · PixelCut 批量抠图工作台（yang-pixelcut）

本地运行、**完全免费**、**输出与原图同分辨率**的批量 AI 抠图工具。

支持拖入整个文件夹批量处理；集成全球主流开源抠图模型（RMBG-2.0 / BiRefNet / U²-Net），并内置 SAM 点选精修、CLIPSeg 提示词补全、ViTMatte 发丝级精细边缘。

> 图片全程在本机处理、不上传任何服务器；原图 5464×5464，抠出来仍是 5464×5464。

---

## ✨ 特性

- **批量**：把图片或整个文件夹拖进窗口任意位置，确认后一键抠图
- **原分辨率输出**：输出 PNG 与原图分辨率完全一致
- **多模型可选**：全球最强 RMBG-2.0（默认）/ 完整增强 RMBG+HRSOD / BiRefNet（高清·人像·至尊·显著目标）/ U²-Net（通用·人像）
- **精细边缘**：ViTMatte 神经网络发丝级抠图，毛发/镂空更准
- **点选精修（SAM）**：在图上点几下补全缺失区域（如椅子），支持 ViT-B 快速 / ViT-L 精准两档
- **提示词补全（CLIPSeg）**：输入"椅子/帽子/chair…"自动补全物体，中英文均可
- **批量补全**：一次补全所有已完成图片的同一物体
- **并发加速**：1/2/3 档并发，多核更快
- **体验细节**：设置记忆 / 失败重试 / 文件去重 / 灯箱缩放 / 内存预检 / 模型损坏检测 / Ctrl+V 粘贴 / 全窗拖放 / 总进度条 / 帮助中心与首次引导

## 🚀 快速开始

### 方式 A：绿色版（推荐，拷贝即用）

完整绿色版体积较大（`models` 约 6GB + `runtime` 约 500MB），受 GitHub 单文件 100MB 限制，**模型与运行环境不存放在本仓库内**。

如果你已有完整绿色版文件夹（如 `本地批量抠图（洋）`），把其中的两个目录拷贝到本项目根目录：

```
models/
runtime/
```

然后双击 `启动抠图工具.bat`，浏览器自动打开操作页面，即可使用。无需安装任何东西。

### 方式 B：从源码运行

1. 安装 **Python 3.10+**（64 位）
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 启动服务：

```bash
python server.py
```

浏览器自动打开 `http://127.0.0.1:8532/`。

> 首次选择某个模型时会自动联网下载对应模型文件（几百 MB 到 1GB，保存到 `models/models/`），下载完成后自动可用。若网络受限，可从绿色版直接拷贝 `models` 目录。


## 🧠 模型说明

|---|---|
