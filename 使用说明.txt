  PixelCut 批量抠图工具（绿色版）· 使用说明
════════════════════════════════════════════

【怎么用】
1. 双击「启动抠图工具.bat」，浏览器会自动打开操作页面
2. 把 图片 或 整个文件夹 直接拖进页面（也可以点"选择图片 / 打开文件夹"）
3. 图片先加入"待处理"列表 —— 不会马上处理
4. 确认无误后，点「一键抠图」→ 自动逐张批量抠图
5. 完成后：
   - 透明背景 PNG 自动保存在「本文件夹\抠图结果\批次文件夹\」
   - 页面里可点「下载全部 ZIP」打包下载，或点单张「下载」

【核心特点】
- 输出分辨率与原图完全一致（原图 5464×5464，抠出来还是 5464×5464）
- 全部在本机处理，图片不会上传到任何服务器，没有数量限制、不收费
- 支持格式：JPG / PNG / WebP / BMP / TIFF
- 模型已全部内置，离线可用，无需联网

【模型选择】（右上角切换，默认已是效果最好的 RMBG-2.0）
- 完整增强 · RMBG+HRSOD：两个最强模型融合 + 边缘保护，人物+椅子等相连
  前景保留最完整（对"人坐椅子"这类图最推荐）
- 全球最强 · RMBG-2.0（默认）：单模型里最强，边缘/细节最精细
- 显著目标 · BiRefNet-HRSOD：专为高分辨率大图设计
- 高清 · BiRefNet-Lite：边界准、速度快
- 人像专精 · BiRefNet-Portrait：人物轮廓更准
- 至尊 · BiRefNet-Massive：更大模型
- 通用 · 更快（U²-Net）：速度快
- 人像 · U²-Net Human：只适合抠人
- 「精细边缘」：升级为 ViTMatte 神经网络边缘细化（比旧版 alpha matting
  更快、发丝/镂空恢复更好，并自动去除边缘残留背景色），适合毛发、镂空图
  注意：追求"主体最完整"时可不开精细边缘；追求"边缘最细"时再开

【点选精修】（手动补全，解决自动抠不干净的区域）
适用：自动抠图后仍有区域缺失/想保留（如椅子、支架、镂空细节）。
1. 抠图完成后，点卡片上的「精修」按钮
2. 默认「＋加」模式：在图上点击要保留的区域（绿色圆点，可点多个）
3. 若抠多了要去掉：切「－减」模式，点击要去除的区域（红色 × 标记）
4. 标注点可按住拖动微调位置
5. 可选 SAM 模型：
   - SAM · 快速(ViT-B)：默认，速度快、够用
   - SAM · 精准(ViT-L)：模型更大，复杂场景更准，稍慢
6. 点「应用」→ 缺失区域被补全、多余区域被去除，结果自动更新
7. 不满意可继续点更多点再精修

【提示词补全】（输入文字自动补全物体）
适用：知道缺什么物体（如椅子、帽子、包、植物），但不想手点。
1. 抠图完成后，点卡片上的「精修」→ 再点「提示词补全」
2. 输入要补全的物体提示词，中文或英文均可（如 椅子 / chair / 帽子 / hat）
   也支持复合描述，如「戴帽子的女人」会自动提取物体词补全帽子
   也可直接点下方常用词快捷按钮（椅子/帽子/包/人/头发/鞋/植物/手机）
3. 点「应用」→ 自动定位该物体并补全到结果里（边缘自动做软边羽化）
4. 识别不到时提示换词，可再用「点选精修」精准补

【并发处理】（多核电脑加速）
- 右上角「并发」选 1/2/3：
  - 1 · 最稳（默认）：逐张处理，内存占用最小
  - 2 / 3 · 快：同时处理多张，速度快，但更吃内存
- 低内存电脑（<8GB）建议保持 1；大图建议保持 1

【批量补全】（一次补全所有已完成图片的同一物体）
适用：多张图都缺同一物体（如批量人坐椅图都缺椅子）。
1. 先「一键抠图」完成所有图片
2. 点工具栏「批量补全」
3. 输入提示词（中文/英文，如 椅子 / chair）
4. 自动逐张补全；每张能识别的补上，识别不到的那张跳过并提示
- 每张约 1~3 秒，多张请耐心等待

【下载所选】
- 勾选卡片左上角的小方框（可多选）→ 点工具栏「下载所选」→ 只打包下载勾选的结果

【其他优化（已内置）】
- 设置记忆：模型 / 并发 / 精细边缘 / SAM 档位自动记住，刷新或下次打开不丢失
- 失败重试：某张处理失败时，卡片出现「重试」按钮，一键重跑
- 文件去重：误拖了重复文件（同名+同大小）自动跳过
- 灯箱缩放：查看原图/结果时可滚轮缩放、按住拖动，方便检查发丝/边缘细节
- 内存预检：处理超大图前自动估算所需内存，不足时提前提示换轻量模型，避免卡死
- 模型损坏检测：模型文件损坏时明确提示（查看 server.log），不再含糊报错
- 缩略图降采样：一次加入很多图片时界面依然流畅

【新增强化功能】
- 使用帮助：页面右上角「使用帮助」→ 完整使用说明 + 常见问题（FAQ）
- 首次引导：第一次打开自动 3 步引导（可跳过，只弹一次）
- 总进度条：工具栏显示「已完成 X/Y」整体进度，多图批量一目了然
- 批量补全可停止：补全中按钮变「停止补全」，随时中断
- Ctrl+V 粘贴：截图/剪贴板图片直接 Ctrl+V 加入列表，无需保存文件
- 精修角标：精修/补全过的卡片显示「已精修」标识
- 原图分辨率：卡片直接显示每张图的原始像素
- 全窗拖放：把图片拖到窗口任意位置都会高亮提示并接收
- 刷新保护：抠图/补全进行中关页面会弹确认，防止误关丢进度
- 超时兜底：单张处理超时（5 分钟）自动提示停止，不再无限等待

【内存管理（自动）】
- 工具会自动按"最近使用"保留最多 4 个模型会话，长时间不用的模型自动释放，
  避免内存越用越多；默认模型 RMBG-2.0 始终常驻。
- 服务日志保存在「本文件夹\server.log」，出问题可查看。

【关于效果上限（重要）】
- 本工具已集成全球开源最强的抠图模型（RMBG-2.0 = BiRefNet 商业精调版），
  并做了双模型融合增强 + SAM 交互式点选精修 + CLIPSeg 提示词补全。
- 对「白底 / 纯色背景 / 简单背景」的图：效果接近完美，主体完整、背景全去。
- 对「复杂户外背景 + 人坐椅」这类图：自动抠图无法 100%，这是技术极限
  （RMBG-2.0 能保留 91~93% 前景）。此时用「完整增强」模型，或用「点选精修」
  手动点几下补全椅子等区域，即可接近完整。

【拷贝到其他电脑】
整个文件夹复制到任意 Windows 电脑，双击「启动抠图工具.bat」即可使用。
无需安装 Python、无需联网下载模型。

【退出】
关闭黑色的命令行窗口即可退出服务。

【常见问题】
- 提示"无法连接本地服务"：先运行「启动抠图工具.bat」再打开页面
- 图片处理慢：大图在高精模式下每张几十秒，属正常；想快切"高清"或"通用·更快"
- 首次加载 RMBG-2.0（977MB）需十几秒，属正常
- 完整增强模式会加载两个大模型（约 2GB 内存），若电脑内存 <8GB 建议用 RMBG-2.0
- 点选精修首次使用会加载 SAM 模型（ViT-B 约 360MB / ViT-L 约 1.2GB），需几秒
- 提示词补全首次使用会加载 CLIPSeg 模型（约 130MB）
