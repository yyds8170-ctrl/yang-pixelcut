PixelCut 使用帮助

快速上手（3 步）

① 拖入图片 / 整个文件夹

把图片或整个文件夹拖到页面任意位置（或点「选择图片 / 打开文件夹」）。支持 JPG / PNG / WebP / BMP / TIFF。选好后不会立即抠图，先进入列表等待确认。

② 点「一键抠图」

确认无误后点击「一键抠图」，工具会用所选模型批量处理。全程在本机处理，图片不上传网络；输出 PNG 与原图分辨率完全一致（5464×5464 原图抠出来仍是 5464×5464）。

③ 精修 / 补全 / 下载

单张结果不理想 → 点卡片「精修」手动加区域，或「提示词补全」输入物体名。全部完成可「下载全部 ZIP」或勾选后「下载所选」。

模型怎么选（顶部下拉）

全球最强 · RMBG-2.0（默认）

综合效果最好的通用抠图，人物/商品/杂物都稳。首选。

完整增强 · RMBG+HRSOD（最完整）

两个模型取并集，最不容易丢东西（如人+椅连坐场景），速度较慢、更吃内存。

高清 · BiRefNet-Lite（快）

速度与效果平衡，适合大批量、对速度有要求。

人像专精 · BiRefNet-Portrait / 人像 · U²-Net Human

专注人物主体，头发/身体轮廓更贴。

至尊 · BiRefNet-Massive / 显著目标 · HRSOD

大数据训练/高分辨率模型，细节更强但慢。适合对效果有极致要求。

通用 · 更快（U²-Net）

最轻量最快，日常快速预览或低配电脑用。

精细边缘

顶部开关「精细边缘」

开启后使用 ViTMatte 网络做发丝级抠图，毛发、镂空、半透明边缘更准，速度变慢（单张约 40s+）。对发丝要求高时开启。

并发（多核加速）

同时处理几张

1·最稳（默认）逐张处理、内存最小；2 / 3 更快但更吃内存。低内存电脑或大图请保持 1。

点选精修（SAM）

手动补全/去除区域

结果图下方点「精修」→ 在图上点击要保留的区域（绿色点，如椅子），或切「－减」点击去除误抠部分（红色点）。点可拖动微调，完成后点「应用」。「SAM 档位」可选快速（ViT-B）或精准（ViT-L）。

提示词补全（CLIPSeg）

输入物体名自动补全

点「提示词补全」，输入要保留的物体中文或英文（椅子 / chair / 帽子 / 包…），点「应用」自动识别并补上。有常用词快捷按钮。

批量补全

一次补全所有已完成图片

所有图都缺同一物体（如都缺椅子）时：先「一键抠图」→ 点工具栏「批量补全」→ 输入提示词，自动逐张补全。可随时点「停止」中断。

下载

下载全部 ZIP / 下载所选 / 单张下载

「下载全部 ZIP」打包当前批次全部结果；勾选卡片左上角方框后「下载所选」只打包勾选的；每张卡片也有「下载」按钮。结果同时自动保存到 本文件夹\抠图结果\ 的批次目录。

快捷键 & 小技巧

Ctrl+V 粘贴入列

截图/剪贴板里的图片直接 Ctrl+V 加入列表，无需保存文件。灯箱内可滚轮缩放、按住拖动细看发丝边缘。

常见问题

首次选某个模型时需要联网下载（几百 MB 到 1GB），下载完成后自动可用。若网络慢可稍等重试；所有模型已随工具一起打包，正常情况下直接可用。
模型文件下载不完整导致。查看 server.log 确认哪个模型，删除 models\models\对应文件夹 后重新下载完整文件，或换其他模型继续用。
图片太大或并发太高。建议：① 换「高清 / 通用·更快」轻量模型 ② 并发改回 1 ③ 关闭 Photoshop 等大程序后重试。
这是自动抠图模型普遍难点（模型默认只认"主体"）。解决办法：① 换「完整增强 · RMBG+HRSOD」模型（并集最全）② 用「点选精修」在缺失处点绿色保留 ③ 用「提示词补全」输入 chair 自动补。
开启顶部「精细边缘」（ViTMatte 发丝级）会明显改善；也可以用「提示词补全」输入 hair 补发丝，或点选精修手动加。
单张上限约 1 亿像素（足够 5464×5464 并留余量）。更大的图建议先缩小到 6000px 内再抠。
自动保存到 本工具文件夹\抠图结果\ 下的按时间命名的批次目录，点工具栏「打开结果夹」直达。也可随时「下载 ZIP」。
整个文件夹（含 models 模型和 runtime 运行环境）拷贝到任意 Windows 电脑，双击「启动抠图工具.bat」即可，无需安装任何东西。首次启动若被杀毒软件拦截，选「允许」即可。
多为内存不足或模型损坏。关掉大程序、并发改 1 重试；仍闪退看 server.log 末尾错误，或重启电脑后再试。
